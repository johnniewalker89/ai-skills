# AI Skills

Самостоятельный набор для написания, проверки и оптимизации ClickHouse/Greenplum SQL.

Две точки входа: `clickhouse-sql` и `greenplum-sql` — выбери нужную СУБД,
остальные скилы агент подключит автоматически.

| Скил | Назначение |
| --- | --- |
| `clickhouse-sql` | Написание, проверка и оптимизация SQL и DDL с учётом особенностей ClickHouse. |
| `greenplum-sql` | Написание, проверка и оптимизация SQL и DDL с учётом распределения данных и параллельного выполнения в Greenplum. |
| `sql-quality-core` | Проверка источников, детализации данных, соединений, метрик и временных окон. |
| `sql-style-core` | Единое оформление и читаемость SQL. |

Для доступа к БД рекомендую использовать Profi MCP в [LiteLLM Workspace](https://litellm-workspace.x340.org/).

Для установки передай агенту ссылку на этот репозиторий и попроси установить все четыре скила из таблицы выше.
